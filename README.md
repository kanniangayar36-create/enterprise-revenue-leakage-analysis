# Enterprise Revenue Leakage & Profitability Intelligence System

## Overview
This project analyzes hidden revenue leakage and profitability issues in a mid-size enterprise.
It focuses on identifying margin erosion, discount misuse, and loss-making customers using
SQL and Python.

## Business Problems
- Declining margins despite revenue growth
- High customer churn
- Unexplained operational cost spikes
- Discount misuse and revenue leakage

## Tools Used
- Python (pandas, numpy)
- SQL (DuckDB / SQLite)
- GitHub

## Project Structure
data/ → Raw data (synthetic)
sql/ → SQL schema and queries
src/ → Python analysis scripts
reports/ → Executive and business reports

## Key Analysis
- Contribution Margin
- Customer Lifetime Value (CLV)
- Cost-to-Serve
- Revenue vs Profit divergence
- Scenario simulations

Work in progress – under active development.
